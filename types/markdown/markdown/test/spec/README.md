# Markdown spec examples

The reader is checked against the examples of these specs, vendored
unchanged:

- `commonmark-0.31.2.txt`: the [CommonMark Spec](https://spec.commonmark.org/0.31.2/)
  0.31.2 by John MacFarlane, from
  [commonmark/commonmark-spec](https://github.com/commonmark/commonmark-spec/blob/0.31.2/spec.txt).
- `gfm-0.29-extensions.txt`: the extension sections (tables, task list
  items, strikethrough, autolinks, disallowed raw HTML) of the
  [GitHub Flavored Markdown Spec](https://github.github.com/gfm/) 0.29, from
  [github/cmark-gfm](https://github.com/github/cmark-gfm/blob/master/test/spec.txt).

Both are licensed under the
[Creative Commons Attribution-ShareAlike 4.0 license](https://creativecommons.org/licenses/by-sa/4.0/).
The second file holds excerpts of the original.

Where the editor reads an example differently on purpose, `spec_test.dart`
lists it with the reason.

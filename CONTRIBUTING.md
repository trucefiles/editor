# Contributing

Thanks for wanting to help make Truce better! Every bug report, idea and
pull request counts.

## Ideas and bugs

Open an [issue](https://github.com/trucefiles/editor/issues). For a bug,
the steps to reproduce it, your platform and the app version help a lot.
Planning a bigger change? Open an issue first, so we can agree on the
approach before you put in the work.

## Pull requests

- Keep each pull request to one change. They're squash-merged, so the
  title and description become the commit message.
- Follow the coding standards in [CLAUDE.md](CLAUDE.md). They apply to
  every contribution, whether written by hand or with an AI assistant.
- Add or update tests with every change; a bug fix comes with a test that
  fails without it.
- Run the checks from the [README](README.md#development) before you push,
  so CI stays green.

# Contributing

Thanks for helping. Bug reports and ideas go in
[issues](https://github.com/trucefiles/editor/issues); for a larger change,
open an issue first so we can agree on the approach.

## Pull requests

- One logical change per pull request. Pull requests are squash-merged, so
  the title and description become the commit message.
- Follow the coding standards in [CLAUDE.md](CLAUDE.md). They apply to every
  contribution, written by hand or with an AI assistant.
- Every change ships with new or updated tests; a bug fix gets a test that
  fails without it.
- Run the checks from the [README](README.md#development) before pushing.
  CI must stay green.

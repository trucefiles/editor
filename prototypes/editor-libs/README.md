# Editor library prototype (throwaway)

Checks whether super_editor and AppFlowy Editor can serve as view/input on
top of the line model, with every write byte-exact. Not part of the app;
never merged. `lib/checklist.dart` is a copy of core's `Checklist` plus a
prototype `applyBlocks`.

Run: `flutter create --platforms=linux .` once, then `flutter test`.
